# QuickSynth

QuickSynth turns an Unreal Engine level into a labeled image dataset for training object detection and segmentation
models. You list your objects, place a camera and a box to spawn them in, press one button, and get images with YOLO,
COCO and segmentation labels that are pixel-exact, with no Blueprint, code or Python.

This guide teaches you how to use it. For every setting's exact default and every output file's exact format, see
the [Feature Reference](reference/workflow.md).
