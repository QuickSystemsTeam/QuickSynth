# 1. Requirements and installation


- **Unreal Engine 5.3, 5.4, 5.5, 5.6, 5.7 or 5.8** on **Windows (64-bit)**.
- Any GPU that runs Unreal Engine. Nothing else to install: QuickSynth doesn't need Python or any other download.

Install QuickSynth from Fab into your engine, then in your project open **Edit → Plugins**, search for
**QuickSynth**, tick it and restart the editor. You'll see:

- a **QuickSynth** category in the **Place Actors** panel (Manager, Capture Camera, Spawn Volume, Lighting Randomizer),
- a **QuickSynth** button on the level editor toolbar,
- **QuickSynth → Object Library / Material Set** when you right-click in the Content Browser.
